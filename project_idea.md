## Rough sketch to finished icon
Input a quick sketch of, say, a house, tree, bicycle, or cat.
The MLP identifies the object; the VAE completes or tidies the drawing for use as an icon.
Google’s [Quick, Draw!](https://github.com/googlecreativelab/quickdraw-dataset/blob/master/README.md) dataset provides **28×28** grayscale drawings.
Download only 5–10 categories and a fixed number of examples per category, not the entire dataset.
